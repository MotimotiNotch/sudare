# Sudare

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/motimotinotch)

> 顔のモザイクを、現像のように確かめて直す。

フォルダの写真から顔を見つけて、**全部にモザイクをかけた状態**で並べる。顔でないものに付いた枠は外し、見落とした顔には枠を足して、原本の隣にモザイク版を書き出す。外した・足したという指定はフォルダに残るので、あとで開き直して直せる。

写真はこの PC の中だけで扱う。外部との通信もアカウントも無い。

名前は日本語の「**簾**（すだれ）」から。向こうの気配は通しつつ、人の顔だけを隠す。

---

## 何が違うのか

顔にぼかしやモザイクをかけるツールは多い。Sudare が気にしているのは、**確かめて直すことと、たくさんの枚数を扱うことを両立させる**こと。

- **初めから全部にかかっている**。押し忘れは「かけすぎ」の側に倒れる（逆にすると、押し忘れが顔の出た写真になる）
- **顔が見つからなかった写真も隠さない**。下のパネルで「顔あり／顔なし」を切り替えられ、見落としは「顔なし」の側に紛れているので、そちらも眺められる
- **指定はサイドカーに残す**。画像を作るのは「書き出す」を押したときだけ。現像ソフトと同じで、何度でもやり直せる
- **書き出す写真はチェックで選ぶ**。濃さは写真ごとに1つ

## 仕組み

1. 顔を見つける学習済みのモデル（OpenCV の [YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)）をこの PC の中で動かし、顔らしい場所を枠で推定する。推論は純 Rust の [tract](https://github.com/sonos/tract) で、外部のランタイムは要らない
   - 自信が 0.6 以上の枠は「見つけた顔」として最初からかける。0.3〜0.6 は「**候補**」として、かけずに右のパネルに畳んで見せる（奥の小さい顔はここに入りやすい。手元の 181 枚で測ると、候補のうち顔は1〜2割だったので、最初からはかけない）
2. 枠を頬や髪まで少し広げ、その範囲を粗いマスに置き換える（枠の幅を N マスにつぶす。N が濃さ）
3. 書き出すときは、原本から作り直して `<名前>_mosaic.jpg` に書く。原本には触れない

> **モデルの推定は完全ではない。** 顔でないもの（動物・ポスター・模様など）にモザイクをかけたり、横顔・小さい顔・暗い顔・一部が隠れた顔にかけなかったりすることがある。**書き出す前に、必ず目で確かめてほしい。**

## 使い方

画面の一つ一つの説明は、アプリのヘッダーの **「使い方」** にある（初めて開いたときにも出る）。ここは流れだけ。

1. **フォルダを開く**: 対象は、選んだフォルダの**直下の JPG だけ**。下の階層は見ない。`*_mosaic.jpg` は対象から外す
2. **一括でかける**: 開くと写真を読み込み、「一括でかけますか」と聞いてから顔を探す。枚数が多いと時間が掛かる。途中で止めても済んだ分は残り、続きはヘッダーから
3. **確かめて直す**
   - 赤い枠が見つけた顔。**枠をクリック**すると外れ（灰色の破線）、もう一度で戻る
   - 写真の上を**ドラッグで囲む**と枠を足す（琥珀色）。「外す」モードで囲むと、中心が入った枠をまとめて外す。**Shift を押している間だけ逆のモード**
   - 右のパネルには顔の切り抜きが並ぶ。全体表示では点になる小さい顔も、ここでなら外せる
   - パネルの下の「**候補 N**」も見る。顔が混じっていたら、クリックでかける
   - ホイールで拡大、右ドラッグで移動、ダブルクリックで全体
   - 濃さは右上のスライダー（右ほど粗い）
4. **書き出す**: チェックの入った写真を書き出す。顔ありは最初から入、顔なしは切。書き出したあとに指定を変えると「書き出し後に変更」と出る

## 書き出すもの・残すもの

| ファイル | 中身 |
| --- | --- |
| `<名前>_mosaic.jpg` | モザイク版（JPEG 品質 92）。同じフォルダに作る。もう一度書き出すと上書きする |
| `mosaic.json` | サイドカー。写真ごとに、見つけた枠・外した番号・足した枠・候補とかけた候補の番号・濃さ・チェック・書き出したときの指定 |

書き出しの EXIF は、原本の EXIF から**残す項目だけを数え上げて組み直す**。消したいものを数えて消すのではないので、新しい種類の情報が増えても、黙って持ち込まれない。

- **残す**: 撮影日時（とタイムゾーン）・カメラとレンズ・露出（シャッター速度・絞り・ISO・補正・測光・フラッシュ・焦点距離・ホワイトバランス）・色空間・撮影者と著作権
- **書き換える**: 向き（画素に焼き込んで 1 に）・更新日時（書き出した時刻）・ソフトウェア（`Sudare`）
- **入らない**: **位置情報（GPS）**・**埋め込みの縮小画像**（モザイク前の顔が写っている）・メーカーノート・ほか全部

## 状態

**個人用の試作（0.1）。Windows だけ。配布はまだしていない。**

```
bun install
bun run typecheck
bun run release              # インストーラ → src-tauri/target/release/bundle/nsis/
bun run release --no-bundle  # exe だけ → src-tauri/target/release/sudare.exe
```

`bun run release` は、ライセンス表記（`licenses/`）を焼き直してから、手元のパス（ユーザー名を含む）を exe に残さない指定を付けて Tauri でビルドする。配るものは `bun run tauri build` ではなくこちらで作る。

## 設計

| ファイル | 役割 |
| --- | --- |
| `src-tauri/src/detect.rs` | 顔の検出。YuNet を tract で動かす。前処理・デコード・NMS は OpenCV の `FaceDetectorYN` と同じ手順を書き直したもの |
| `src-tauri/src/photo.rs` | 読み込み（向きを焼き込む）・縮小・モザイク・書き出し・EXIF の組み直し |
| `src-tauri/src/lib.rs` | 画面から呼ぶコマンド6つ（`scan` / `save_sidecar` / `detect_faces` / `preview` / `crops` / `export`） |
| `src-tauri/models/yunet_2023mar_dyn.onnx` | 入力の高さ・幅を可変にした YuNet。重みは元のまま |
| `src/ui/app.ts` | 画面。状態はサイドカーの中身1つに持ち、変えたら描き直して保存する |
| `src/ui/tour.ts` | チュートリアルと「このツールについて」 |
| `scripts/gen-app-icon.ts` | アイコンの生成 |
| `scripts/gen-licenses.ts` / `scripts/release.ts` | ライセンス表記の生成 / 配るものを作る |

枠の座標はすべて原寸の画素で持つ。画面では縮小画像の上に、書き出しと同じ考え方でモザイクを重ねて見せている。
